- [ ] **[4-tower-5](../books/created_unitygames/4-tower-5.md) `[QueryKey]` 属性と `UIViewSection<T>` の出所が不明**
  - 何が問題か:
    - `[QueryKey("back-button")]` というアトリビュートと、`UIViewSection<ShopMenuUIViewSection>` という自己参照ジェネリクスが説明なしに登場する。
  - なぜ問題か:
    - 自作クラスなのか外部ライブラリなのかが読者に伝わらず、実装を試みた際に詰まる。
    - とくに `[QueryKey]` は UI Toolkit の標準 API にも存在しないため、初見では意味が取れない。
  - どう対応すればよいか:
    - 「`UIViewSection` は自作の基底クラスで、`[QueryKey]` アトリビュートも自作」といった一言注記を追加する。

- [ ] **[4-tower-5](../books/created_unitygames/4-tower-5.md) `_presentation` / `_application` フィールドが未定義のまま登場する**
  - 何が問題か:
    - `HomeSceneContext` のコードサンプル内で `_presentation.Camera.Movable`、`_presentation.UINavigator`、`_application.StartHomeSession` などが随所に使われているが、これらのフィールドはコード例中のどこにも定義・注入されていない。
  - なぜ問題か:
    - コードを上から読んでも「`_presentation` とは何か」が分からず、設計の全体像が掴みにくい。
  - どう対応すればよいか:
    - フィールド定義（`[Inject]` 注入部分）をコードサンプルに追加する。
    - または「`_presentation` は〇〇を集約したオブジェクト」といった説明文を補足する。

### 🟡 中優先度

- [x] **[4-tower-6](../books/created_unitygames/4-tower-6.md) `BootstrapSceneContext` に注入した `_loadSceneRequest` が未使用に見える**
  - 何が問題か:
    - `[Inject] private readonly IPublisher<LoadSceneRequest> _loadSceneRequest` と宣言しているが、メソッド本体では `_presentation.LoadSceneRequest.Publish(...)` が使われており、注入したフィールドが使われていない。
  - なぜ問題か:
    - コードの意図が分からず「このフィールドは何のために宣言しているのか」と混乱する。デッドコードにも見える。
  - どう対応すればよいか:
    - フィールド宣言を削除する（`_presentation` 経由で呼べるなら不要）。
    - または `_presentation.LoadSceneRequest` が内部的にこのフィールドを使っているなら、その旨を注記する。

- [x] **[4-tower-6](../books/created_unitygames/4-tower-6.md) `_delaySeconds` の定義が示されていない**
  - 何が問題か:
    - `BootstrapSceneContext` の `UniTask.Delay((int)(_delaySeconds * 1000))` でフィールドを参照しているが、どこで定義・設定されるかがコード例にない。
  - なぜ問題か:
    - `[SerializeField]` で設定するのかハードコードなのかが分からず、コード断片として中途半端な印象を与える。
  - どう対応すればよいか:
    - `[SerializeField] private float _delaySeconds = 0f;` の一行をコードサンプルに追加する。

  - どう対応すればよいか:
    - `[Inject] private readonly SessionManager _sessionManager = default!;` などをコードサンプルに追加する。

- [ ] **[4-tower-1](../books/created_unitygames/4-tower-1.md) `ValueObject` の説明順序が前後している**
